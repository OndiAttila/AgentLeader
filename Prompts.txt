The user should be able to specify the model name as a command line parameter, as well as during the execution of the program.
If the model name is not otherwise specified, use a default value instead.
Allow the user to send a new query (after the LLM responded to the last one) as many times as the user desires.
The program should use the streaming HTTP protocol to send the queries (and receive the responses) and periodically send the necessary "ping" messages to keep the connection alive,
even if the user has not sent a query within the wait period of 1 minute.
If the streaming HTTP connection is closed for any reason, the program should try to reestablish the connection 5 times, before notifying the user about the error.
